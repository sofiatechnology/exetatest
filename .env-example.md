# Email Provider

Default strategy: **Nodemailer (SMTP) first**, then **Resend** if SMTP fails.

```env
EMAIL_PROVIDER=smtp-resend
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=user@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM=noreply@yourdomain.com
RESEND_API_KEY=re_xxxxxxxxxxxxx
FROM_EMAIL=hello@mail.yourdomain.com
```

| `EMAIL_PROVIDER` | Behavior |
|------------------|----------|
| `smtp-resend` (default) | Nodemailer → Resend on failure |
| `smtp` / `nodemailer` | Nodemailer only |
| `resend` | Resend only |
